# LIBERTY v2 の使い方

1. 「希望表の取り込み」で期間とファイルを選ぶ。写真・PDFはページごとに読み取る。
2. 原本の氏名・年月日・行列が合っているか確認。不明セルを修正し、判読できたセルを照合済みにする。
3. 希望を反映し、スタッフ画面で部署と契約を確認。KB双葉は4h/8h、未確認の契約は配置対象外。
4. 「シフト生成」で対象期間、部署別休館、祝日扱い、短縮営業を登録して生成。
5. 「監査・調整」で問題をタップすると該当日・セルへ移動。セルを開いて勤務・休憩を編集。手動変更は再生成で保持できる。元に戻す・やり直すに対応。
6. 「Excel出力」で6シートを書き出す。ハード違反は修正が必要。不足等が残る案は調整用であることを確認する。
7. 端末移動・ブラウザデータ削除前にJSON保存する。途中の原本はJSONに含まれないため別途保管。

旧版データは元の保存領域に保全。v2で再確認してから利用する。旧版JSONの保存ボタンから、過去の割当も含む原本を取得できる。

原本に対応する認識結果・信頼度・セル位置を保持する。画像では選択セルを青枠で表示。CSV/XLSXではシート名とセル番地を表示。原本から断定できないセルは、確認操作後も勤務可能へ変換しない。
